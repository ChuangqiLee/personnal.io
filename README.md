# Chuangqi Li — Personal Website

Personal website imported from `DerrickLee-main.zip`.

Live website: https://chuangqilee.github.io/chuangqili.github.io/

## Publishing

GitHub Pages serves the `docs/` directory on the `main` branch.
Commit changes to `docs/` and push to `main` to update the website.

## Local preview

```sh
python3 -m http.server 8000 --directory docs
```

Open http://localhost:8000/ in a browser.
